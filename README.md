# Rúbrica MKT — Evaluación de Presentaciones Finales

Aplicación HTML autónoma en un único archivo ([`index.html`](./index.html)) para evaluar las presentaciones finales de Marketing (`2627-88051-A INGLÉS`, 9 grupos / 40 alumnos) a lo largo de **3 días distintos** y exportar las calificaciones en formato **CSV listo para importar en Canvas LMS**.

## Uso rápido

1. Abre [`index.html`](./index.html) directamente en cualquier navegador moderno (Chrome, Edge, Safari o Firefox). No requiere servidor ni conexión a internet.
2. Organiza y filtra los 9 grupos entre **Día 1**, **Día 2** y **Día 3** (editable en cualquier momento desde la cabecera de cada grupo).
3. Puntúa cada criterio de la rúbrica (Bloque A: 75 % contenido; Bloque B: 25 % exposición oral; pesos totalmente editables en el botón **Pesos**).
4. Aplica ajustes individuales (`+` / `-` puntos) a cada integrante del equipo si procede (acotado automáticamente entre `0.00` y `10.00`).
5. Todo el progreso se guarda automáticamente en el navegador (`localStorage`). Si vas a cambiar de ordenador entre días, utiliza el botón **Respaldo** para exportar/importar un archivo `.json`.
6. Pulsa **Exportar CSV Canvas** para descargar el archivo `.csv` con una nueva columna de tarea sobre **10.00 puntos** (`Final Project Presentation` por defecto, personalizable) e impórtalo desde **Canvas → Calificaciones → Importar**.
